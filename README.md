# Anna Creus · Psicologia

Web professional d'Anna Creus – Psicologia.

## Estat del projecte

Primera maqueta visual en català i castellà. El contingut dels serveis i els textos són provisionals i s'hauran de revisar abans de publicar la web com a consulta activa.

## Fitxers

- `index.html`: estructura i contingut.
- `styles.css`: disseny responsive.
- `script.js`: canvi d'idioma i menú mòbil.

## Vista prèvia local

Obre `index.html` al navegador. No cal instal·lar cap dependència.

## Publicació

Es pot connectar aquest repositori a Cloudflare Pages per desplegar automàticament els canvis de la branca principal. No hi ha cap sistema de reserves ni es recullen dades personals o de salut en aquesta versió.

## Identitat visual

La paleta inicial és una aproximació a la identitat existent: blau verdós suau, blanc trencat i text fosc. Cal confirmar els codis exactes abans de donar-la per definitiva.
